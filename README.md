# SpendWise – Personal Expense Tracker

## Project Description

SpendWise is a personal expense-tracking web application designed to help users manage their finances by recording, organizing, and monitoring their daily expenses.

The application provides a simple and user-friendly interface that makes it easier to keep track of spending and develop better financial management habits.

This project was developed as part of the Web Hosting and Deployment module to demonstrate the process of deploying a web application from a local development environment to the internet.

## Technologies Used

The project was developed using the following technologies:

- **HTML5** – For structuring the web application.
- **CSS3** – For styling and creating a responsive user interface.
- **JavaScript** – For application functionality and interactivity.
- **Git** – For version control.
- **GitHub** – For hosting the project's source code.
- **Netlify** – For hosting and deploying the live website.

## Deployment Process Summary

The following steps were followed to deploy SpendWise:

1. **Project Preparation:** Reviewed the project structure and ensured that all necessary HTML, CSS, JavaScript, and other project files were properly organized.

2. **GitHub Repository Creation:** Created a public GitHub repository named `Web-week7ILO`.

3. **Uploading Project Files:** Initialized Git, added the project files, committed the changes, and pushed the project to GitHub.

4. **Netlify Integration:** Logged into Netlify and connected the GitHub account.

5. **Website Deployment:** Selected the SpendWise GitHub repository and configured the deployment settings before publishing the website.

6. **Custom Site Name:** Changed the default Netlify subdomain to `faisaspendwise.netlify.app` to give the project a meaningful web address.

7. **Automatic Deployment:** Made a visible update to the application, committed the changes, and pushed them to GitHub. Netlify automatically detected the new commit and deployed the updated version of the website.

8. **Final Testing:** Opened the live website and checked that the application loaded correctly and that its pages, styles, scripts, and assets were working as expected.
